# 🌱 مشروع الأمن الغذائي في الأردن

هذا المشروع التفاعلي يسلّط الضوء على واقع الزراعة والأمن الغذائي في الأردن، من خلال تجربة ويب نابضة بالحياة تربط بين البيانات، التصميم، والتفاعل.

## 🎯 الهدف

عرض رحلة البذرة من الزراعة التقليدية إلى الابتكار الحضري، مع التركيز على:

- أنواع الزراعة وأساليبها
- أنظمة الري المستخدمة
- المحاصيل والنباتات المنتشرة
- الأمراض النباتية وتأثيرها
- الزراعة العمودية في المدن
- رحلة النمو من البذرة إلى الثمرة

## 🧠 المميزات التقنية

- واجهة تفاعلية تعتمد على مؤثرات بصرية وحركية
- رسم بياني ديناميكي باستخدام [Chart.js](https://www.chartjs.org/)
- نظام بحث ذكي للمحاصيل والنباتات
- دعم الوضع الليلي والنهاري
- خلفيات متغيرة حسب نوع الصفحة
- تنظيم الكود في ملفات مستقلة (`app.js`, `script.js`, `search.js`, `splash.js`)
- مصدر بيانات موحد عبر `data/data.json`

## 🚀 ملاحظات

- الموقع قيد التطوير، وقد لا تظهر بعض الصفحات أو الرسوم البيانية بشكل كامل في النسخة المنشورة على GitHub Pages.
- الكود منظم وجاهز للتوسع، ويعكس تجربة تصميمية قابلة للتخصيص حسب السياق المحلي.
- يمكن تشغيل المشروع محليًا عبر فتح `index.html` في المتصفح، بشرط أن تكون الملفات في نفس المسارات.

## 💡 أفكار مستقبلية

- إضافة دعم للغة الإنجليزية
- ربط البيانات بواجهة إدارة محتوى (CMS)
- عرض تفاعلي ثلاثي الأبعاد لمراحل النمو
- دمج خرائط توزيع المحاصيل حسب المناطق
