# مشروع الأمن الغذائي في الأردن

تجربة تفاعلية نابضة بالحياة تستعرض رحلة البذرة من قطرة ماء إلى الاكتفاء، عبر صفحات غنية بالمعلومات والتصميم البصري.

## 🎯 الفكرة
المشروع يربط البرمجة بالقضايا المجتمعية، ويقدم محتوى تعليمي حول الزراعة والأمن الغذائي في الأردن بأسلوب قصصي وتفاعلي.

## 📁 مكونات المشروع
- شاشة بداية متحركة تمثل بذرة تنبض بالحياة
- صفحات متعددة: الزراعة، الري، المحاصيل، الأمراض، الزراعة العمودية
- وضع ليلي/نهاري ديناميكي
- خلفية مرسومة بالكود تمثل السماء حسب الوقت
- مؤثرات بصرية لكل مرحلة من مراحل نمو النبات

## 🚀 طريقة التشغيل
1. افتح `index.html` في متصفح حديث
2. تأكد من وجود مجلد `app/` ويحتوي على:
   - `app.js`
   - `splash.js`
   - `script.js`
3. تأكد من وجود ملف `style.css` في الجذر
4. استمتع بالتجربة التفاعلية

## 🧠 تقنيات مستخدمة
- HTML / CSS / JavaScript
- Canvas API للرسم التفاعلي
- LocalStorage لحفظ الوضع الليلي
- IntersectionObserver لمراقبة ظهور العناصر


بناميا – مهتم بدمج البرمجة مع التصميم القصصي والقضايا المحلية، ويبحث دائمًا عن تجربة نابضة بالحياة في كل صفحة.
